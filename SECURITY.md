# Security

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/justdataplease/art-history-museum/security/advisories/new)
rather than a public issue. Include the affected URL or file and steps to
reproduce; we'll reply there.

The site is static-first (prerendered galleries, no user accounts, no user
data); the optional Postgres connection is read-only from the app.
